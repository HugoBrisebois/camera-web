# camera-web
a simple website that lets photographers know when the best time is to go out and take photos and and will include some other tools too


# How to use
in order to use this web app to its fullest potential, you need to get an api key from www.weatherapi.com and get your api key for the weather module of the app. the app will automatically encrypt it with the master password that you will provide, after that just input your camera gear and see what the app offers
